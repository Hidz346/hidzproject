Kebijakan Privasi

HidzProject adalah kumpulan project dan tools web buatan Hidz. Halaman ini menjelaskan data apa saja yang disimpan saat kamu memakai HidzProject, untuk apa dipakai, dan bagaimana login dengan Google atau GitHub diproses.

Terakhir diperbarui: 14 November 2026

Data yang kami simpan

  • Data akun: username, password, peran akun, masa aktif, dan batas perangkat. Password disimpan dalam bentuk hash satu arah, jadi tidak bisa dibaca siapa pun, termasuk admin.
  • Identitas Google atau GitHub (kalau kamu masuk lewat salah satunya): ID akun Google beserta alamat emailnya, atau ID akun GitHub beserta username dan alamat emailnya. Hanya itu yang disimpan. Foto profil dan data lain tidak disimpan.
  • Data pemakaian akun: perangkat yang sedang masuk, waktu login dan logout, serta notifikasi akunmu.
  • Data pembelian VIP: paket, nominal, status pesanan, dan kode voucher yang dipakai. Data kartu atau e-wallet tidak pernah kami terima, pembayaran QRIS diproses oleh Midtrans.
  • Pesan di fitur chat dan izin notifikasi browser, kalau kamu memakai fitur tersebut.
  • Alamat IP dan perkiraan lokasi (negara, kota) dari server, dipakai untuk keamanan: membatasi percobaan login berulang dan memblokir penyalahgunaan.

Login dengan Google dan GitHub

Kamu bisa membuat akun dan masuk lewat Google atau GitHub. Kami hanya meminta identitas dasar: nama, alamat email, dan ID akun. Itu dipakai untuk satu hal, yaitu mengenali akunmu saat masuk.

Kami tidak membaca atau mengubah isi akun Google dan GitHub kamu (email, file, kontak, repositori, dan sejenisnya), dan tidak memposting apa pun atas namamu. Setelah masuk, kamu tetap membuat username dan password HidzProject sendiri, dan itu yang dipakai untuk login berikutnya.

Informasi yang diterima dari Google tidak dipakai untuk iklan dan tidak dibagikan ke pihak lain. Kamu bisa mencabut akses kapan saja lewat pengaturan keamanan akun Google atau pengaturan Applications di akun GitHub.

Untuk apa data dipakai

  • Membuat akunmu, mengenali kamu saat masuk, dan menjaga masa aktif serta batas perangkat.
  • Memproses pembelian VIP dan mengaktifkannya ke akunmu.
  • Mengirim notifikasi yang berkaitan dengan akunmu, misalnya status permintaan ganti username atau password.
  • Menjaga keamanan layanan dari penyalahgunaan.

Data tidak dijual, tidak disewakan, dan tidak dipakai untuk iklan.

Layanan pihak ketiga

Agar HidzProject berjalan, data diproses oleh layanan berikut:

  • Google dan GitHub untuk fitur masuk dengan akun mereka.
  • Google Firebase untuk penyimpanan data akun dan notifikasi.
  • Vercel sebagai tempat situs berjalan.
  • Cloudflare Turnstile untuk memeriksa bahwa pengunjung bukan bot.
  • Midtrans untuk pembayaran QRIS paket VIP.

Masing-masing punya kebijakan privasinya sendiri.

Mode tamu

Masuk sebagai tamu tidak membuat akun dan tidak menyimpan data pribadi apa pun. Tamu hanya bisa melihat daftar project dan membuka profil.

Menyimpan dan menghapus data

Data akun disimpan selama akunmu ada. Kalau kamu ingin akun dan datanya dihapus, atau ingin memperbaiki data yang salah, hubungi admin lewat kontak di bawah dengan menyebutkan username akunmu. Permintaan ganti username atau password juga diproses admin dan baru berlaku setelah disetujui.

Keamanan

Semua koneksi memakai HTTPS. Password di-hash sebelum disimpan, dan akses ke penyimpanan data dibatasi. Tidak ada sistem yang sepenuhnya kebal, jadi gunakan password yang unik dan jangan membagikannya.
